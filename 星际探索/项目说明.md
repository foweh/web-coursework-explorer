## 三、实现的功能清单

### 3.1 轮播图（首页 Hero 区域）
- **按钮切换**：左右箭头点击切换幻灯片
- **圆点切换**：底部 3 个指示器点击跳转
- **自动轮播**：每 4 秒自动切换，鼠标悬停暂停、移出恢复
- **切换动画**：淡入淡出 + 缩放效果

### 3.2 视频播放（explore.html）
- 嵌入 Pexels 免费太空视频（外链 MP4）
- 自定义控制栏：播放/暂停、进度条点击跳转、音量滑块
- 实时显示当前时间 / 总时长

### 3.3 Tab 切换效果（4 处）
- **登录页**：登录 / 注册 面板切换
- **探索页**：太阳 / 行星 / 小行星带 内容切换
- **画廊页**：全部 / 星云 / 星系 / 天文摄影 筛选
- **资讯页**：最新 / 发射任务 / 天文发现 分类切换
- 所有 Tab 切换均带淡入上移动画

### 3.4 列表展示效果
- **首页**：特色板块 3 卡片、热门探索 3 卡片、数据统计 4 项
- **探索页**：行星卡片网格（太阳区 3 张、行星区 6 张、小行星区 3 张）
- **画廊页**：9 张图片网格 + 悬浮覆盖层标题
- **资讯页**：9 条图文新闻列表

### 3.5 交互动画（≥3 种）
- **hover 动画**：卡片上移悬浮 + 边框发光 + 图片缩放、行星卡片 3D 倾斜跟随鼠标旋转
- **滚动动画**：`IntersectionObserver` 驱动的淡入上移（`.fade-in-up`），进入视口触发
- **过渡动画**：导航下拉展开/收起、Tab 切换、灯箱打开/关闭、按钮悬浮缩放

### 3.6 计时 / 时间显示
- **实时时钟**（首页底部）：显示当前年月日、星期、时分秒（每秒更新）
- **倒计时**（资讯页）：距离 2026 年 1 月 1 日的实时倒计时（天/时/分/秒）

### 3.7 表单验证（登录/注册）
- **Tab 切换**：登录 ↔ 注册面板自由切换
- **非空验证**：所有字段必填
- **格式验证**：邮箱正则、密码长度 ≥6、用户名 2-20 字符
- **确认密码**：两次输入一致性校验
- **实时反馈**：失焦（blur）触发验证，输入时自动清除错误
- **提交反馈**：成功/失败提示消息，3 秒自动消失

## 五、技术要点

| 技术 | 应用 |
|------|------|
| **HTML5** | 语义化标签：`<header>`、`<footer>`、`<section>`、`<article>`、`<main>` |
| **CSS3** | CSS 变量主题色、Flexbox + Grid 布局、`backdrop-filter` 毛玻璃、`@keyframes` 动画、`IntersectionObserver` 驱动动画、响应式 3 档断点（900px / 768px / 500px） |
| **JavaScript** | 原生 ES6、DOM 操作、事件委托、`setInterval` 计时、视频 API、灯箱、正则表单验证 |
| **无框架** | 纯手写，零依赖，无 Bootstrap/Tailwind/jQuery |
| **图片** | 全部本地文件，无外链，便于离线运行 |
