# 星际探索 · 静态网页课程作业

> 宇宙科普与太空探索主题的静态站点，共 6 个页面：首页轮播、登录注册、太阳系探索、太空画廊、资讯、小测验。
> A six-page static website about space exploration — plain HTML / CSS / JS, no framework, no build.

## 页面

| 页面 | 文件 | 内容 |
| --- | --- | --- |
| 首页 | `index.html` | 轮播图、特色板块、热门探索卡片、实时数据与时钟 |
| 登录 / 注册 | `login.html` | Tab 切换的登录与注册表单 |
| 太阳系探索 | `explore.html` | 行星分类 Tab、行星卡片网格、视频播放器 |
| 太空画廊 | `gallery.html` | 图片筛选 Tab、画廊卡片、灯箱放大 |
| 资讯 | `news.html` | 太空新闻列表 |
| 小测验 | `quiz.html` | 太空知识问答 |

## 技术

- 原生 HTML / CSS / JavaScript，无框架、无构建、无依赖
- 全站共享 `css/` 与 `js/`，图片素材在 `images/`
- 双击 `index.html` 即可运行，页面间通过导航栏串联

## 目录

```
星际探索/
├── index.html  login.html  explore.html  gallery.html  news.html  quiz.html
├── css/       全站样式
├── js/        交互脚本（轮播、筛选、灯箱、测验判分）
├── images/    图片素材
└── 项目说明.md  设计与页面结构说明
```
